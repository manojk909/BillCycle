## Goal
Professional-looking emails for the reset link (Scene A) and sending invoices (Scene D). These are **pure functions**: data in, `{ subject, html, text }` out. No mail sending here (M6 owns `sendMail`).

## Build `server/src/templates/email/`
```ts
export type EmailContent = { subject: string; html: string; text: string };

// layout.ts
export function emailLayout(opts: { title: string; bodyHtml: string; footer?: string }): string;

// reset-password.ts
export function resetPasswordEmail(p: { name: string; link: string; expiresInMinutes: number }): EmailContent;
// invoice-sent.ts
export function invoiceSentEmail(p: { customerName: string; invoiceNumber: string; total: string;
  dueDate: string; periodLabel: string; link: string }): EmailContent;
// overdue-reminder.ts
export function overdueReminderEmail(p: { customerName: string; invoiceNumber: string; amountDue: string;
  dueDate: string; daysOverdue: number; link: string }): EmailContent;
// portal-invite.ts
export function portalInviteEmail(p: { customerName: string; link: string; expiresInMinutes: number }): EmailContent;

// index.ts re-exports all
```
Rules: inline CSS only (email clients), table-based layout, max width 600 px, brand colour `#714B67`, big button for the link plus the raw link as text, **HTML-escape every input** (write a small `escapeHtml` helper), plain-text version always included.

## Acceptance criteria
- [ ] Vitest: each template contains the link and amount, and escapes `<script>` in names
- [ ] Rendered HTML files saved in `server/src/templates/email/__preview__/` (generated by a small script) so the team can open them in a browser
- [ ] Screenshot in the PR
